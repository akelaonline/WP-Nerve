# WPNerve 0.1.0-alpha.14 — Product UI & Operator Experience

Alpha.14 is the first WPNerve build packaged as a cohesive operator-facing product rather than a collection of security/runtime surfaces.

## Highlights

- New top-level **WPNerve** admin area.
- Product-grade Dashboard with connection health, credentials, pending confirmations, risk classes and client configuration.
- Professional **Diagnostics** screen backed by the live WordPress Abilities registry.
- **HTTP Smoke** screen for authenticated public-HTTPS MCP validation using a temporary, automatically revoked Application Password.
- In-product **Documentation** screen covering setup, security, risk classes, diagnostics and product scope.
- Exact v1 catalog contract remains **53 reviewed abilities**.
- README, WordPress readme, security policy and translation template refreshed for the current product surface.

## Real staging evidence

Before this UI release, the alpha.12 operational smoke passed on a real WordPress staging site:

- 53/53 registered abilities;
- 53/53 discoverable abilities in explicit full-surface staging mode;
- REST route + schema checks;
- `server/discover`;
- `tools/list` returning 53 tools;
- `site-status` and `list-plugins`;
- draft creation and content update;
- destructive confirmation issuance and administrator approval;
- trash and restore;
- unauthenticated endpoint rejection with HTTP 401.

## Package QA

The alpha.14 installable ZIP was validated locally after the UI/documentation pass:

- 56 PHP files pass `php -l`;
- 81 archive entries under a single `wp-nerve/` root;
- no tests, scripts, vendor tree, CI metadata or development-only Composer files in the installable package;
- no absolute paths, traversal components or case-insensitive path collisions;
- required runtime entry point, uninstall handler, admin stylesheet and Dashboard/Diagnostics/HTTP Smoke/Documentation classes present;
- archive integrity passes.

## Security posture

This release does not weaken WPNerve's default security model. Privileged and Destructive risk classes remain opt-in and continue to require out-of-band confirmation. Full-surface mode is a disposable-staging diagnostic control, not a recommended production default.

## Status

Alpha.14 is an operational pre-release. Independent security review, the complete supported WordPress/PHP/Multisite matrix and final release-lifecycle evidence remain gates before a production-ready label.
